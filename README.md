# 점심시간 교실 탈출

초등학교 5학년 1학기 수학 「다각형의 둘레와 넓이」 복습용 방탈출 웹앱입니다.

## 포함 기능
- 30분 타이머
- 교실 안 물건 클릭 탐색
- 5개의 수학 문제
- 정오각형 둘레 → 열쇠 획득
- 평행사변형 / 삼각형 / 마름모 / 사다리꼴 넓이 문제
- 인벤토리
- 단서 수첩
- 힌트 3회
- 최종 비밀번호 7294
- 탈출 성공 화면

## GitHub에 올리는 방법
1. 이 폴더의 `index.html`, `style.css`, `app.js`, `assets` 폴더를 모두 업로드합니다.
2. GitHub 저장소에서 Commit changes를 누릅니다.
3. 이후 Cloudflare Pages 또는 Workers에 저장소를 연결해 배포할 수 있습니다.

중요: ZIP 파일 자체를 GitHub에 올리는 것이 아니라, ZIP을 풀고 그 안의 파일/폴더를 올려야 합니다.
